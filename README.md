# Welcome to Quest01
***

## Task
/* What is the problem? And where is the challenge? */
This project introduces the core fundamentals of C programming through 21 progressive exercises (`ex00` to `ex20`). The main challenge is mastering C's strict static typing, conditional logic, loops, functions, return values, ASCII character checks, and low-level standard output using the `write()` system call.

## Description
/* How have you solved the problem? */
Each exercise (`ex00` through `ex20`) is implemented in its corresponding directory as a standalone C source file:
```
- **Compilation & Variables (`ex00`–`ex05`):** Compiling C files with `gcc` and declaring/modifying `int`, `char`, and string (`char *`) variables.
- **Control Flow & Functions (`ex06`–`ex12`):** Implementing `if/else` statements, logical operators (`&&`, `||`), `while` loops, `void` and typed return functions, and sign checks.
- **Standard Library Reproductions & ASCII (`ex13`–`ex20`):** Rebuilding `my_abs`, `my_isalpha`, `my_isdigit`, `my_islower`, `my_isupper`, and `my_isspace` using ASCII value ranges, and printing the lowercase alphabet forward and in reverse using `write()`.
```

## Installation
/* How to install your project? npm install? make? make re? */

No package manager or Makefile is required. Compile any individual C exercise using `gcc`:
```
gcc -Wall -Wextra -Werror -o my_project ex00/my_first_compilation.c
```
## Usage
/* How does it work? */

Run the compiled binary from your terminal, or verify all exercises 
using Qwasar's automated test runner:
```
./my_project 
gandalf
```
